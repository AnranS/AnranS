Hi, I'm **Anran**. I work on LLM inference and AI infrastructure, and I learn by building things from scratch, running them, and measuring the results.

**Blog:** [anrans.github.io](https://anrans.github.io/) — notes on inference systems, GPU programming, and AI infra.

### LLM inference

- [**nano-vllm-rs**](https://github.com/AnranS/nano-vllm-rs) — Single-GPU Qwen3 inference in Rust + CUDA, with reproducible benchmarks.
- [**mini-sglang-mlx**](https://github.com/AnranS/mini-sglang-mlx) — mini-sglang rebuilt on Apple Silicon with MLX: paged KV, radix cache, Metal attention.
- [**sglang-interactive-guide**](https://github.com/AnranS/sglang-interactive-guide) — An interactive SGLang guide in Chinese that runs offline and needs no GPU.
